## 1. 快速开始

1. 将可执行文件放在任意目录，首次运行会自动创建 `scripts/` 子目录。
2. 在 `scripts/` 目录下新建一个 `.lua` 文件（如 `my_script.lua`）。
3. 编写脚本（至少包含 `meta` 表和 `on_loop` 函数），保存。
4. 运行引擎，按 **F10** 重载脚本列表，按 **F12** 切换当前脚本。
5. 按 `meta.trigger_key`（默认 F9）触发/停止脚本。

---

## 2. 脚本文件结构

一个完整的脚本由以下部分组成（均为全局变量/函数）：

```lua
-- ① 元数据（必须）
meta = { ... }

-- ② 行为参数（可选，有默认值）
settings = { ... }

-- ③ 辅助函数（可选，任意数量）
local function helper() ... end

-- ④ 启动回调（可选）
function on_start() ... end

-- ⑤ 主循环（必须）
function on_loop() ... end

-- ⑥ 停止回调（可选）
function on_release() ... end
```

脚本加载时引擎会先**执行一次全部顶层代码**（初始化 meta、settings、局部函数），
然后按照触发模式循环调用 `on_loop`。

---

## 3. meta 表（元数据）

```lua
meta = {
    name         = "脚本名称",       -- 显示在控制台的名称
    description  = "功能描述",       -- 说明文字（仅供展示）
    trigger_key  = "F9",             -- 触发热键（见第 7 节）
    trigger_mode = "toggle",         -- 触发模式（见下表）
    target_class = "",               -- 目标窗口类名（空 = 全局生效）
}
```

### trigger_mode 取值

| 值       | 行为                                     |
|----------|------------------------------------------|
| `"toggle"` | 按一次开始，再按一次停止（默认）        |
| `"hold"`   | 按住触发键时执行，松开立即停止          |
| `"once"`   | 按一次执行完整的 `on_loop` 一遍后自动停止 |

### target_class 说明

- 留空（`""`）：脚本全局生效，不管哪个窗口在前台。
- 填入窗口类名（如 `"UnityWndClass"`）：仅当目标窗口处于前台时脚本才会运行；坐标自动从窗口客户区换算为屏幕绝对坐标。
- 获取类名方法：使用 Spy++、WinSpy 等工具，或在脚本中用 `log()` 配合系统工具确认。

## 4. settings 表（行为参数）

```lua
settings = {
    default_click_hold  = 30,   -- 鼠标/键盘点击默认按住时长（毫秒）
    default_post_delay  = 15,   -- 每个带延迟 API 调用后的默认等待（毫秒）
    global_speed        = 1.0,  -- 全局速度系数（2.0 = 快一倍，0.5 = 慢一倍）
}
```

`default_post_delay` 的实际值 = `default_post_delay / global_speed`，
因此提高 `global_speed` 会等比缩短所有默认延迟。

若脚本中省略 `settings`，引擎将使用上述默认值。

## 5. 生命周期函数

| 函数          | 必须 | 调用时机                          |
|---------------|------|-----------------------------------|
| `on_start()`  | 否   | 脚本开始执行时调用一次            |
| `on_loop()`   | **是** | 每次循环调用（`once` 模式下只调用一次） |
| `on_release()`| 否   | 脚本停止时调用一次（即使出错也会尝试调用） |

> **注意**：`on_loop` 内部抛出错误（`error()`）会终止脚本，引擎会在日志中打印错误信息。  
> 调用 `stop()` 可以在 `on_loop` 内部主动停止脚本。

## 6. API 参考

### 6.1 鼠标操作

#### `mouse_move(x, y [, abs [, delay_ms]])`

移动鼠标到指定坐标。

| 参数       | 类型    | 默认值 | 说明                                            |
|------------|---------|--------|-------------------------------------------------|
| `x`        | integer | —      | X 坐标                                          |
| `y`        | integer | —      | Y 坐标                                          |
| `abs`      | boolean | `true` | `true` = 绝对坐标；`false` = 相对当前位置的偏移 |
| `delay_ms` | integer | 设置值 | 移动后等待的毫秒数（覆盖 `default_post_delay`） |

```lua
mouse_move(960, 540)           -- 绝对移动到 (960, 540)
mouse_move(10, -5, false)      -- 相对当前位置移动 (+10, -5)
mouse_move(960, 540, true, 50) -- 绝对移动后等待 50ms
```

---

#### `mouse_click_rand(x1, y1, x2, y2 [, btn [, hold_ms [, delay_ms]]])`

在矩形区域内随机选取一个坐标，移动鼠标后点击。

| 参数       | 类型    | 默认值           | 说明                                         |
|------------|---------|------------------|----------------------------------------------|
| `x1`, `y1` | integer | —                | 区域左上角坐标                               |
| `x2`, `y2` | integer | —                | 区域右下角坐标                               |
| `btn`      | string  | `"left"`         | 按键名称（见下表）                           |
| `hold_ms`  | integer | `default_click_hold` | 按住时长（毫秒）                         |
| `delay_ms` | integer | 设置值           | 点击后等待（毫秒）                           |

```lua
-- 在 [666,542]~[753,633] 区域内随机左键单击
mouse_click_rand(666, 542, 753, 633)

-- 随机区域内右键单击，按住 50ms
mouse_click_rand(100, 200, 300, 400, "right", 50)
```

> 坐标大小顺序不做强制要求，引擎会自动取 min/max。

---

#### `mouse_click(btn [, hold_ms [, delay_ms]])`

点击鼠标按键（按下 + 等待 + 抬起）。

| 参数       | 类型    | 默认值           | 说明                     |
|------------|---------|------------------|--------------------------|
| `btn`      | string  | —                | 按键名称（见下表）       |
| `hold_ms`  | integer | `default_click_hold` | 按住时长（毫秒）     |
| `delay_ms` | integer | 设置值           | 点击后等待（毫秒）       |

鼠标按键名称：

| 名称                          | 对应按键   |
|-------------------------------|------------|
| `"left"` / `"lbutton"`        | 鼠标左键   |
| `"right"` / `"rbutton"`       | 鼠标右键   |
| `"middle"` / `"mbutton"`      | 鼠标中键   |

```lua
mouse_click("left")           -- 左键单击
mouse_click("right", 50)      -- 右键按住 50ms
mouse_click("left", 30, 200)  -- 左键按住 30ms，之后等待 200ms
```

---

#### `mouse_down(btn)` / `mouse_up(btn)`

单独的鼠标按下 / 抬起，不带内置延迟。

```lua
mouse_down("left")
delay(500)       -- 手动控制持续时间
mouse_up("left")
```

---

### 6.2 键盘操作

#### `key_click(key [, hold_ms [, delay_ms]])`

敲击键盘按键（按下 + 等待 + 抬起）。

| 参数       | 类型    | 默认值               | 说明                 |
|------------|---------|----------------------|----------------------|
| `key`      | string  | —                    | 按键名称（见第 7 节）|
| `hold_ms`  | integer | `default_click_hold` | 按住时长（毫秒）     |
| `delay_ms` | integer | 设置值               | 点击后等待（毫秒）   |

```lua
key_click("F")          -- 按 F 键
key_click("SPACE", 50)  -- 按空格键并按住 50ms
key_click("E", 30, 100) -- 按 E 键，按住 30ms，之后等待 100ms
```

---

#### `key_down(key)` / `key_up(key)`

单独的键盘按下 / 抬起，用于实现组合键。

```lua
key_down("CTRL")
key_click("C", 30)   -- Ctrl+C
key_up("CTRL")

key_down("SHIFT")
key_click("A", 30)   -- Shift+A（大写 A）
key_up("SHIFT")
```

### 6.3 延迟与冷却

#### `delay(ms)`

暂停执行指定毫秒数。每 10ms 检查一次停止信号，可被触发键中断。

```lua
delay(1000)   -- 等待 1 秒
delay(0)      -- 无操作（不报错）
```

---

#### `delay_rand(min_ms, max_ms)`

在 `[min_ms, max_ms]` 范围内随机等待一段时间，模拟人工操作节奏。同样可被触发键中断。

| 参数      | 类型    | 说明              |
|-----------|---------|-------------------|
| `min_ms`  | integer | 最短等待毫秒数    |
| `max_ms`  | integer | 最长等待毫秒数    |

```lua
delay_rand(200, 1000)  -- 随机等待 200ms ~ 1000ms
delay_rand(500, 500)   -- 等同于 delay(500)
```

---

#### `cooldown(tag, ms) → boolean`

基于命名标签的冷却计时器。  
- 若距上次调用未超过 `ms`，返回 `false`（冷却中）。  
- 若已超过 `ms` 或首次调用，记录当前时间并返回 `true`（可执行）。

```lua
-- 每 5 秒执行一次技能
if cooldown("skill_q", 5000) then
    key_click("Q", 30)
end

-- 多个独立冷却
if cooldown("heal", 3000) then key_click("H", 30) end
if cooldown("buff", 10000) then key_click("B", 30) end
```

### 6.4 颜色检测

> 颜色格式统一为 `"#RRGGBB"` 十六进制字符串，大写，如 `"#FF0000"` 表示纯红色。

#### `get_color(x, y) → string`

获取屏幕指定坐标的像素颜色，返回 `"#RRGGBB"` 格式字符串。

```lua
local c = get_color(960, 540)
log("中心点颜色: " .. c)

if c == "#FF0000" then
    log("检测到红色")
end
```

---

#### `wait_color(x, y, color [, timeout_ms]) → true`

等待指定坐标出现目标颜色。  
- 匹配成功：返回 `true`。  
- 超时：**抛出错误**，脚本终止。

| 参数         | 类型    | 默认值 | 说明               |
|--------------|---------|--------|--------------------|
| `x`, `y`     | integer | —      | 检测坐标           |
| `color`      | string  | —      | 目标颜色 `#RRGGBB` |
| `timeout_ms` | integer | `5000` | 超时时间（毫秒）   |

```lua
-- 等待加载画面消失（白色消失），最多等 10 秒
wait_color(960, 540, "#FFFFFF", 10000)
-- 之后执行后续操作
mouse_click("left", 30)
```

---

#### `if_color(x, y, color [, timeout_ms]) → boolean`

检测指定坐标是否出现目标颜色。  
- 匹配成功：返回 `true`。  
- 超时：返回 `false`（**不报错**）。

| 参数         | 类型    | 默认值 | 说明               |
|--------------|---------|--------|--------------------|
| `x`, `y`     | integer | —      | 检测坐标           |
| `color`      | string  | —      | 目标颜色 `#RRGGBB` |
| `timeout_ms` | integer | `50`   | 检测等待上限（毫秒）|

```lua
-- 快速轮询：是否有可捡取的道具图标
if if_color(100, 100, "#FFD700", 50) then
    key_click("F", 30)
end
```

### 6.5 OCR 文字识别

#### `ocr_region(x1, y1, x2, y2) → string`

对屏幕指定矩形区域进行 OCR 文字识别，返回识别出的文本字符串。

| 参数   | 类型    | 说明                   |
|--------|---------|------------------------|
| `x1`   | integer | 区域左上角 X           |
| `y1`   | integer | 区域左上角 Y           |
| `x2`   | integer | 区域右下角 X           |
| `y2`   | integer | 区域右下角 Y           |

> 需要安装对应语言的 **Windows 语言包**，引擎启动时会提示 OCR 是否可用。

```lua
-- 识别右上角状态区域
local text = ocr_region(1600, 20, 1900, 80)

if text:find("确认") then
    mouse_click("left", 30)
elseif text:find("取消") then
    key_click("ESC", 30)
end
```

### 6.6 工具函数

#### `log(msg)`

向控制台输出日志，前缀为 `[LUA]`。

```lua
log("当前步骤：购买弹药")
log("颜色值: " .. get_color(500, 300))
```

---

#### `stop()`

在 `on_loop` 内部主动停止脚本（等效于用户按下触发键停止）。

```lua
function on_loop()
    local hp = ocr_region(100, 50, 300, 90)
    if hp:find("0") then
        log("角色已死亡，停止脚本")
        stop()
    end
    -- 后续代码不会执行
end
```

---

#### `exec(program [, args [, wait]]) → integer`

启动一个外部程序，可选等待其退出并返回退出码。

| 参数      | 类型    | 说明                                               |
|-----------|---------|----------------------------------------------------|
| `program` | string  | 可执行文件名或完整路径                             |
| `args`    | table   | （可选）参数列表，按顺序传给程序                   |
| `wait`    | boolean | （可选）`true` = 等待程序退出后返回；默认 `false`  |

**返回值**：`wait=true` 时返回程序退出码（整数）；`wait=false` 时返回 `0`。

> 子进程以 `CREATE_NO_WINDOW` 方式启动，stdin/stdout/stderr 均重定向到空设备，  
> 不会继承父进程的控制台句柄，因此不会导致引擎控制台冻结。

```lua
-- 强制结束游戏进程（不等待）
exec("taskkill", {"/F", "/IM", "EscapeFromTarkov.exe"})

-- 启动记事本并等待用户关闭，获取退出码
local code = exec("notepad.exe", {}, true)
log("退出码: " .. code)

-- 使用完整路径运行程序
exec("C:/Games/Launcher.exe", {"--silent", "--autostart"})
```

---

#### `import(module_name)`

加载并执行 `scripts/` 目录下的另一个 Lua 文件。  
`module_name` 不需要 `.lua` 后缀，支持子目录路径（用 `/` 分隔）。

```lua
import("common/utils")         -- 加载 scripts/common/utils.lua
import("商人子弹/点击购买")    -- 加载 scripts/商人子弹/点击购买.lua
```

### 6.7 截图

#### `screenshot(path [, x, y, w, h]) → path`

截取屏幕并保存为 PNG 文件。

| 参数   | 类型    | 默认值       | 说明                                                          |
|--------|---------|--------------|---------------------------------------------------------------|
| `path` | string  | —            | 保存路径（如 `"D:/shot.png"` 或相对路径 `"shot.png"`）        |
| `x`    | integer | `0`          | 截取区域左上角 X（省略则从 0 开始）                           |
| `y`    | integer | `0`          | 截取区域左上角 Y（省略则从 0 开始）                           |
| `w`    | integer | 屏幕宽度     | 截取宽度（省略则取全屏宽度）                                  |
| `h`    | integer | 屏幕高度     | 截取高度（省略则取全屏高度）                                  |

**返回值**：传入的 `path` 字符串，便于链式调用。

若 `target_class` 非空且指定了 `x`/`y`，坐标会自动从窗口客户区转换为屏幕坐标。

```lua
-- 全屏截图，保存到当前目录
local path = screenshot("shot.png")

-- 截取屏幕左上角 400×300 区域
local path = screenshot("region.png", 0, 0, 400, 300)

-- 截图后立即发送到企业微信
local KEY = "your-webhook-key"
webhook_file(KEY, screenshot("alert.png"))
```

### 6.8 Webhook 通知

#### `webhook(key, content [, mention])`

向企业微信机器人发送文本通知，常用于脚本出错时告警。

| 参数      | 类型   | 默认值   | 说明                                         |
|-----------|--------|----------|----------------------------------------------|
| `key`     | string | —        | 企业微信 Webhook Key（URL 中 `key=` 后的部分）|
| `content` | string | —        | 通知内容                                     |
| `mention` | string | `"@all"` | 被提醒人的手机号，或 `"@all"` 提醒所有人     |

```lua
local KEY = "693axxx6-7aoc-4bc4-97a0-0ec2sifa5aaa"

-- 提醒所有人
webhook(KEY, "脚本运行出错，请检查！")

-- 提醒指定手机号
webhook(KEY, "任务已完成", "13800138000")
```

> 若请求失败（网络错误或 HTTP 非 2xx），会抛出 Lua 错误并终止脚本。  
> 建议用 `pcall` 包裹以避免因网络问题中断脚本：
>
> ```lua
> local ok, err = pcall(webhook, KEY, "出错了！")
> if not ok then log("webhook 失败: " .. err) end
> ```

---

#### `webhook_upload_file(key, file_path) → media_id`

将本地文件上传到企业微信媒体库，返回 `media_id`（3 天内有效）。

| 参数        | 类型   | 说明                                          |
|-------------|--------|-----------------------------------------------|
| `key`       | string | 企业微信 Webhook Key                          |
| `file_path` | string | 本地文件路径（绝对路径或相对路径均可）        |

```lua
local KEY = "693axxx6-7aoc-4bc4-97a0-0ec2sifa5aaa"
local media_id = webhook_upload_file(KEY, "D:/shot.png")
log("已上传，media_id: " .. media_id)
```

---

#### `webhook_send_file(key, media_id)`

通过 `media_id` 向企业微信机器人发送文件消息。

| 参数       | 类型   | 说明                                     |
|------------|--------|------------------------------------------|
| `key`      | string | 企业微信 Webhook Key                     |
| `media_id` | string | 由 `webhook_upload_file` 返回的媒体 ID   |

```lua
local KEY = "693axxx6-7aoc-4bc4-97a0-0ec2sifa5aaa"
local media_id = webhook_upload_file(KEY, "shot.png")
webhook_send_file(KEY, media_id)
```

---

#### `webhook_file(key, file_path)`

便捷函数：一步完成文件上传 + 发送，等同于依次调用 `webhook_upload_file` 和 `webhook_send_file`。

| 参数        | 类型   | 说明                               |
|-------------|--------|------------------------------------|
| `key`       | string | 企业微信 Webhook Key               |
| `file_path` | string | 本地文件路径                       |

```lua
local KEY = "693axxx6-7aoc-4bc4-97a0-0ec2sifa5aaa"

-- 截图并直接发送到企业微信
webhook_file(KEY, screenshot("alert.png"))

-- 用 pcall 防止网络异常中断脚本
local ok, err = pcall(webhook_file, KEY, "report.png")
if not ok then log("发送失败: " .. err) end
```

## 7. 按键名称速查表

按键名称**不区分大小写**（`"f9"` 与 `"F9"` 等效）。

### 字母键

直接使用单个字母：`"A"` ~ `"Z"`

### 数字键

直接使用单个数字：`"0"` ~ `"9"`

### 功能键

| 名称              | 按键                |
|-------------------|---------------------|
| `"F1"` ~ `"F12"`  | F1 ~ F12            |

### 控制键

| 名称                                | 按键       |

## 8. 引擎全局热键

以下热键由引擎全局监听，**不能**被脚本占用作触发键：

| 热键    | 功能                                                                    |
|---------|-------------------------------------------------------------------------|
| `F8`    | 开始/停止操作录制（录制完成自动保存为 `.lua`）                          |
| `F10`   | 重载 `scripts/` 目录（不重启引擎即可更新脚本），并自动恢复上次选中的脚本 |
| `F12`   | 切换到下一个脚本（切换时清屏并重新显示脚本列表）                        |
| `ESC`   | 停止当前脚本并退出引擎                                                  |

**自动记忆上次脚本**：引擎在 exe 同级目录保存 `last_script.txt`，记录上次选中的脚本文件名。
下次启动或按 **F10** 重载时，会自动定位到该脚本，无需手动切换。

**录制功能**：按 F8 开始录制后，引擎会记录所有鼠标移动、点击和键盘输入，
再次按 F8 停止录制，自动生成 `录制_YYYYMMDD_HHMMSS.lua` 文件并重载脚本列表。

## 9. 坐标系说明

### 全局模式（`target_class = ""`）

所有坐标为**屏幕绝对坐标**（像素），原点在屏幕左上角。

### 窗口模式（`target_class = "窗口类名"`）

所有坐标为目标窗口的**客户区坐标**（不含标题栏、边框），引擎自动换算为屏幕坐标。

- 脚本执行期间若目标窗口不在前台，`on_loop` 会**暂停**，直到目标窗口重新获得焦点。
- `mouse_move` 的 `abs=false`（相对模式）时，偏移仍基于当前鼠标屏幕位置，不受窗口坐标影响。

## 10. 模块化与 import

将公共逻辑提取到单独文件，通过 `import` 引入：

```
scripts/
├── my_macro.lua          ← 主脚本
└── common/
    └── buy_utils.lua     ← 公共工具模块
```

```lua
-- common/buy_utils.lua
function click_confirm()
    mouse_move(960, 600, true)
    mouse_click("left", 30, 500)
end
```

```lua
-- my_macro.lua
import("common/buy_utils")   -- 加载后 click_confirm 变为全局函数

function on_loop()
    click_confirm()
end
```

> `import` 会在当前 Lua 环境中执行目标文件，所有在目标文件中定义的全局变量/函数均可在主脚本中使用。

## 11. 完整脚本模板

```lua
-- ============================================================

-- 说明：简要描述脚本功能

meta = {

function on_start()
    log("脚本已启动")
end

-- ── 主循环 ────────────────────────────────────────────────────
function on_loop()
    -- 在此编写主逻辑
    do_something()

end

    log("脚本已停止")
end
```

## 12. 常见模式与技巧

### 等待界面加载后再操作

```lua
function on_loop()
    -- 等待按钮出现（绿色按钮像素点）
    wait_color(960, 700, "#00FF00", 10000)
    mouse_move(960, 700, true)
    mouse_click("left", 30, 500)
end
```

### 条件分支执行

```lua
function on_loop()
    if if_color(50, 50, "#FF0000", 100) then
        -- 危险状态
        key_click("H", 30)
    else
        -- 正常状态
        key_click("Q", 30)
    end
    delay(500)
end
```

### 定时触发（冷却计时器）

```lua
function on_loop()
    -- 每 30 秒触发一次大招
    if cooldown("ultimate", 30000) then
        key_click("R", 30)
    end
    -- 每 5 秒触发一次小技能
    if cooldown("skill", 5000) then
        key_click("E", 30)
    end
    delay(100)
end
```

### 组合键

```lua
-- Ctrl+S 保存
key_down("CTRL")
key_click("S", 30)
key_up("CTRL")

-- Alt+F4 关闭窗口
key_down("ALT")
key_click("F4", 30)
key_up("ALT")
```

### 用 OCR 动态判断

```lua
function on_loop()
    local text = ocr_region(800, 100, 1200, 150)
    log("识别文字: " .. text)

    if text:find("购买") then
        mouse_click("left", 30, 300)
    elseif text:find("确认") then
        mouse_click("left", 30, 300)
    else
        delay(500)
    end
end
```

### 单次执行模式（打开程序、一次性操作）

```lua
meta = {
    name         = "一键打开设置",
    trigger_key  = "F9",
    trigger_mode = "once",   -- 按一次执行完就自动停止
}

function on_loop()
    key_down("CTRL")
    key_click("COMMA", 30)   -- Ctrl+,
    key_up("CTRL")
    delay(500)
end
```

### 主动停止脚本

```lua
local count = 0

function on_loop()
    count = count + 1
    key_click("F", 30)
    delay(500)

    if count >= 10 then
        log("已执行 10 次，自动停止")
        stop()
    end
end
```

### 截图并发送到企业微信

```lua
local KEY = "your-webhook-key"

function on_loop()
    -- 每 5 分钟截一次全屏发到群
    if cooldown("report", 300000) then
        local ok, err = pcall(webhook_file, KEY, screenshot("report.png"))
        if not ok then log("发送失败: " .. err) end
    end
    delay(1000)
end
```

### 异常告警截图

```lua
local KEY = "your-webhook-key"

function on_loop()
    -- 检测到死亡画面（屏幕变红）时截图告警
    if if_color(960, 540, "#AA0000", 100) then
        log("检测到死亡，截图告警")
        local path = screenshot("death_" .. os.time() .. ".png")
        pcall(webhook, KEY, "角色疑似死亡，请检查！")
        pcall(webhook_file, KEY, path)
        delay(10000)  -- 避免频繁告警
    end
    delay(200)
end
```
